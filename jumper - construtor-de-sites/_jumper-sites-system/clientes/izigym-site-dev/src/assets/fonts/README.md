# Fontes IZI — Desenvolvimento 1

Famílias fornecidas pelo usuário em 17/11/2026, também instaladas em ~/Library/Fonts:
- gc-north-sans-demo.zip: GC North Sans Demo SemiBold (600) e Bold (700).
- Obviously Font.zip: Obviously Demo Light (300), Regular (400), Medium (500) e Bold (700).

Os arquivos foram convertidos para WOFF2 sem modificar os desenhos ou adicionar caracteres. Os pesos CSS correspondem aos estilos nomeados, pois a tabela OS/2 dos arquivos Obviously Demo usa valores não convencionais.

O banner usa GC North Sans SemiBold no título e Obviously Light nos textos de apoio; o CTA usa Obviously Medium. O restante do site usa GC North Sans nos títulos e Obviously nos textos e controles, respeitando os pesos de cada componente.

Limitações: GC North Sans Demo contém somente 57 caracteres mapeados; não inclui números, acentos, ordinal feminino e vários símbolos. Obviously Demo contém 66 caracteres e também não inclui os acentos e diversos símbolos. Obviously Support (Regular/Bold), já existente no projeto da LP IZI, e Outfit cobrem os caracteres ausentes. As versões completas são necessárias para reprodução integral da arte.
