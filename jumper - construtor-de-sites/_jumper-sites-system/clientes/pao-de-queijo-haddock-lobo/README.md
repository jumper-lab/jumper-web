## Abrir e construir

Requer Node >=22.12.0 e npm. Astro 7.3.5, saída estática, sem backend ou credenciais.

```sh
npm ci
npm run dev
```

Desenvolvimento: http://127.0.0.1:4327/. Para conferir a versão compilada:

```sh
npm run build
npm run preview
```

Astro 7 gerencia o preview em segundo plano. `npx astro preview status` consulta; `npx astro preview stop` encerra. Para revisar um build novo, recarregar a página; se mudar a configuração de base, reiniciar o preview.

## Refinamento de 02/10/2026

Home com hero fotográfico 100vw × 100vh, usando 100svh no celular para a altura visível segura. Cesta, café e mesa alternam a cada 7,6 segundos, por dissolução de 1,6 segundo e movimento óptico mínimo. A imagem anterior fica opaca sob a nova e conserva o zoom até o fim, evitando escurecimento e salto de escala. Só entra imagem decodificada; falha de rede conserva a cena. Seletores diretos, pausa e ampliação substituem setas. Escolhas rápidas são serializadas com prioridade da última intenção. Seleção manual pausa até retomar; foco/hover em outros controles, diálogo aberto, aba oculta, saída do viewport e movimento reduzido suspendem o autoplay. “Retomar” explícito funciona com mouse/foco mantidos no próprio botão, inclusive pelo teclado. Pagehide/pageshow preservam temporizador e estado no histórico, sem rodar a hero fora da tela.

Cabeçalho fixo com altura, marca e posição de links iguais em todas as páginas, inclusive em 1920px e após rolagem. O espaço do menu está dentro dos 100vh das quatro aberturas; a 404 mantém reserva utilitária. Só na Home, branco/transparente sobre a foto, recua em opacidade ao descer e retorna ao subir/focar, assumindo papel/navy fora do hero sem encolher. Nas internas, menu navy/papel como na composição anterior, sem deslocar links. Navegação sem JavaScript não fica encoberta. Impressão dupla nas letras e tinta pontual nos botões, sem mover hitboxes; títulos/fotos abaixo da dobra mantêm máscaras/faixas. Parallax discreto só na Home em desktop. Assinatura inclusiva: “Uma pausa com história.”; origem factual de 1968 preservada.

Trocas de página usam dissolução nativa curta de 220ms. Foram retiradas a máscara integral de faixas e a animação separada do cabeçalho, que sobrepunham efeitos de entrada. View Transitions CSS funciona como melhoria progressiva entre documentos da mesma origem, sem interceptar links ou atrasar navegação. Movimento reduzido desativa o efeito; outros navegadores navegam normalmente. [Documentação da API CSS](https://developer.mozilla.org/en-US/docs/Web/CSS/@view-transition). Sem biblioteca de animação adicionada. Fontes, conteúdos e hovers da identidade preservados; descrições do cardápio mobile têm pelo menos 12px.

Implementação em `HomeHero.astro`, `NavPrint.astro`, `styles/atelier.css`, `scripts/slideshow.ts` e `scripts/motion.ts`. O DS final, seu preview estático e o prompt executivo refletem esta revisão. Efeitos são progressivos: sem JavaScript há uma fotografia estática e o conteúdo inteiro; movimento reduzido desativa autoplay/transições, mas mantém a seleção manual.

Não inclui blog/admin, reservas, e-commerce ou simulação de pedidos. O pedido de 02/10 autoriza o frontend do formulário de contato, com envio inativo até configuração real. WhatsApp é para eventos; cada loja possui seu telefone público.
